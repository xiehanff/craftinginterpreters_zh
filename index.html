一条完整的实现路线

从扫描、解析到字节码虚拟机，每章结束都有一个可运行的完整解释器版本。

两种实现，两种视角

jlox 用 Java 的树遍历解释器讲解语义；clox 用 C 手写栈式虚拟机，直面前端工程的性能取舍。

译文 + 原文对照

每章保留英文原文段落，与中文译文逐段对照，术语争议处附译者注。

怎么读这本书 ​

  1. 从 导读 开始，先看作者对全书结构和阅读方式的说明。
  2. 第一部分 前言、领土地图、Lox 语言 建立整体框架。
  3. 第二部分跟着 扫描 一路做到 继承，得到完整的 jlox。
  4. 第三部分从 字节码块 做到 优化，得到带垃圾回收的 clox。
  5. 语法与生成的语法树类在 附录 I、附录 II。
